# PyPiPie-TravelDistanceMap
Color mapping of travel distance in pyRevit.

Original authored in Dynamo by Andy_Grout
https://forum.dynamobim.com/t/travel-distance-visualisation/115267
https://cdck-file-uploads-us1.s3.dualstack.us-west-2.amazonaws.com/flex022/uploads/dynamobim/original/3X/4/3/4325846db2a36626b685edc201da0d6b0d6ba1d6.pdf

Select destination points. Run script. Pick face of floor.

Goal is to remove dependency on any Revit families and use the PlanCircuit andd rooms as the input.

This version is for testing and proof of concept.
